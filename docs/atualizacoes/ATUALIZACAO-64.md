# Atualização 64 — objetos de mapa (margens transparentes)

Esta etapa introduz uma primeira melhoria prática no editor de Objetos de Mapa:

- rótulos do editor ajustados para **Comprimento (X, m)** e **Largura (Y, m)**;
- imagens enviadas pelo editor passam a ter **corte automático de margens transparentes** quando detectadas;
- importação em lote de imagens para Objetos de Mapa também usa esse ajuste automático;
- novo botão **"Cortar margens transparentes"** dentro do editor para corrigir manualmente objetos antigos já salvos.

Observações:

- esta atualização não adiciona ainda o lápis manual para remover restos de fundo branco;
- objetos antigos continuam funcionando; para corrigir um deles, basta abrir o objeto no banco, usar o novo botão de corte e salvar novamente.
