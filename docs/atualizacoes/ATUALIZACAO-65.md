# Atualização 65 — limpeza manual de imagens de Objetos de Mapa

Complementa a v64 com uma ferramenta manual para corrigir fundos e halos que a remoção automática não consegue eliminar.

## Editor manual

No editor de Objetos de Mapa há agora o botão **🧽 Limpar manualmente**.

Ele abre um editor com:

- **Apagar**: torna transparentes as partes pintadas;
- **Restaurar**: recupera pixels apagados durante aquela sessão de edição;
- **Tamanho do pincel**;
- **Desfazer** (até 20 passos de pincelada);
- **Reiniciar** para voltar à imagem que entrou no editor;
- **Aplicar à prévia** para devolver a imagem editada ao formulário do objeto.

Depois de aplicar, ainda é necessário clicar em **Salvar objeto** para persistir a alteração no banco.

A ferramenta trabalha apenas no navegador; não usa IA nem serviços externos.
