# Atualização 81 — polimento de sessão e foco no mapa

Esta atualização é deliberadamente visual e não altera regras de combate, Psi, primeiros socorros, comércio, dano ou movimentação.

## Modo foco do Mapa da Mesa

- novo botão **Foco no mapa**;
- oculta o painel de preparação, catálogo e histórico para dar mais espaço vertical ao tabuleiro;
- mantém o painel de ação do personagem disponível;
- o botão muda para **Mostrar painéis** enquanto o modo foco estiver ativo;
- a preferência fica salva localmente no navegador.

## Histórico

- novo botão para mostrar/ocultar o histórico sem apagar nenhum registro;
- entradas passam a ter leitura visual mais clara;
- sucessos, falhas, críticos, dano e Psi recebem marcação visual discreta;
- texto original das mensagens continua intacto;
- preferência de histórico visível/oculto fica salva localmente.

## Cache

- `app.js` e `nova-direta.js` passam a usar a versão 81 para evitar reaproveitamento de módulo antigo pelo navegador.
