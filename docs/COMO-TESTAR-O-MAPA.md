# Como testar o mapa de teste você mesmo (Yuri)

1. Publique (já feito se o Claude avisou) e abra o site com **Ctrl+F5**. Entre como **mestre**.
2. **Aplique a reforma no seu mapa salvo** (uma vez): Ferramentas do mestre → **🛠️ Reformar mapa de teste** → escolha o mapa → aplicar (faz backup antes). Isso traz o canal ligado à lagoa, areia molhada/seca, plantas e pedras, subsolo, lava e os nomes novos das criaturas. *Publicar o site não muda mapas salvos.*
3. Abra o mapa em **🗺️ Mapas**.
4. Ferramentas do mestre → **🧪 Testar o mapa com um personagem**: escolha *Pessoa* ou *Insetoide guerreiro*, marque lanterna/tocha se quiser, **➕ Colocar / trocar**, e use os botões *Ir para* (acampamento, casa, cachoeira, lagoa, torre, alçapão, rampa, lava). Ande com WASD ou segurando o mouse; F/clique interage; escadas, rampas e o alçapão funcionam ao andar para dentro.
5. **🗑️ Remover personagem de teste** apaga só ele.

Dicas: o subsolo é escuro (sem lanterna só a abertura ilumina); a lava queima só com o mestre online; nado = água funda; ondas ao andar em qualquer água.
